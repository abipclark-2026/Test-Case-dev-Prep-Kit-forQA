## Clarification tracker

One row per spec question, from the moment it is raised. IDs are `<STORY-ID>-C1`,
`<STORY-ID>-C2`... and are never reused. Every case affected by an open question
carries a note that cites the ID: `Confirm with spec author (<STORY-ID>-C1): <question>`.

Status: **Open** (asked, waiting) → **Answered** (answer received, not yet applied to
the cases) → **Applied** (cases updated, note replaced with the answer). Use
**Withdrawn** for a question that no longer matters, and say why in the answers table.
